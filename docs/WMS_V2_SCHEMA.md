# WMS V2 Schema Contract

All tables live in PostgreSQL schema `public` unless noted. PKs are `INTEGER GENERATED BY DEFAULT AS IDENTITY` (or `SERIAL`). Timestamps are naive UTC.

Enums are stored as `VARCHAR` and validated in application constants.

---

| Name | Start | Use |
|---|---|---|

## Status / type enumerations

### `clients.active`, `divisions.active`, `warehouses.active`, `division_warehouses.active`

Boolean.

### `users.role`

`ADMIN` | `USER`

### `inventory_units.status`

`AVAILABLE` | `RESERVED` | `PACKED` | `SHIPPED`

### `orders.status`

`UNALLOCATED` | `PARTIALLY_ALLOCATED` | `ALLOCATED` | `PICK_TICKET_READY` | `PROCESSING` | `CLOSED` | `CANCELLED`

### `allocations.status`

`ACTIVE` | `RELEASED`

### `cartons.status`

`OPEN` | `AWAITING_WEIGHT` | `REWEIGH_REQUIRED` | `CLOSED`

### `inventory_transactions.transaction_type`

`IMPORT` | `ADJUSTMENT` | `RESERVE` | `UNRESERVE` | `PACK` | `UNPACK` | `SHIP` | `RETURN` | `TRANSFER_IN` | `TRANSFER_OUT`

### `divisions.operation_type`

`ECOM` | `RTL` | `WHLS`

### `documents.type`

`PICK_TICKET` | `ORDER_CLOSURE` | `PACKING_REPORT` | `BOX_DETAIL`

## Relationship map

```
users 1──* user_permissions *──1 permissions
users 1──* user_clients *──1 clients
users 1──* audit_events

clients 1──* divisions
clients 1──* warehouses
clients 1──* division_warehouses
clients 1──* orders
clients 1──* inventory_units

divisions 1──* division_warehouses *──1 warehouses
divisions 1──* orders

warehouses 1──* inventory_units
warehouses 1──* orders

orders 1──* order_lines
orders 1──* allocations
orders 1──0..1 pick_tickets
orders 1──* cartons
orders 1──0..1 invoices
orders.processing_user_id → users.id

order_lines 1──* allocations

inventory_units 1──* inventory_transactions
inventory_units 0..1 ACTIVE allocations
inventory_units 0..1 carton_contents
```

## Same-client FK expectations (application + trigger)

`warehouse.client_id = inventory_unit.client_id`  
`order.client_id = order.warehouse.client_id = order.division.client_id`  
`allocation.client_id = order.client_id = unit.client_id`  
`carton.client_id = order.client_id`

## Objects not in V2

- `inventory_balances` — forbidden as a second SoR  
- V1 `order_types` — replaced by `divisions.operation_type`  
- V1 global unique `barcode` on units — not required  
- Prisma leftover tables — not created on the V2 database
